### 2. Writing Task 1 (Graph/Chart) — Your Power Words
**Trend verbs:** rise, fall, decline, plummet, soar, surge, plateau, stabilise, fluctuate
**Degree adverbs:** sharply, gradually, steadily, marginally, considerably, substantially
**Comparisons:** whereas, in contrast, compared to, conversely, similarly

### 3. Writing Task 2 (Essay) — Structure + Vocabulary
- **Intro:** paraphrase + thesis (use: *arguably, undoubtedly, this essay will...*)
- **Body 1:** main argument (use: *primarily, largely, predominantly, this is because...*)
- **Body 2:** counterargument + refutation (use: *nonetheless, admittedly, however, conversely*)
- **Conclusion:** summary + recommendation (use: *ultimately, therefore, governments should...*)

### 4. Speaking — Band 7+ Vocabulary Habits
- Replace basic words: *good → beneficial, bad → detrimental, big → substantial*
- Use **collocations**, not isolated words: *tackle climate change*, *bridge the gap*, *raise awareness*
- Use **hedging**: *it could be argued that..., this tends to..., generally speaking...*

### 5. Common Mistakes to Avoid
- ❌ Don't memorise long words you can't use naturally — examiners notice
- ❌ Don't repeat the same linking word (vary: *however, nevertheless, nonetheless, that said*)
- ✅ **Accuracy beats complexity** — a correct B2 word scores higher than a misused C2 word
